## 🎯 Definition

**OAuth 2.0** is an industry-standard authorization framework that enables applications to obtain limited access to user accounts on third-party services. Instead of sharing passwords, OAuth allows users to grant access tokens that specify what actions an application can perform on their behalf.

**Origin:**
- OAuth 1.0 released in 2007 (complex, signature-based)
- OAuth 2.0 published as RFC 6749 in October 2012
- Developed by IETF OAuth Working Group
- Simplified from OAuth 1.0 (no signatures, uses TLS)
- Adopted by Google, Facebook, Microsoft, GitHub, etc.
- Foundation for modern API authorization
- Extended by OpenID Connect for authentication

**Key Principles:**
- **Delegated Authorization** - Users grant limited access without sharing credentials
- **Token-Based** - Access is controlled via tokens, not passwords
- **Scoped Access** - Tokens have limited permissions (scopes)
- **Separation of Concerns** - Authentication vs Authorization separated
- **Short-Lived Tokens** - Access tokens expire quickly for security
- **Refresh Capability** - Long-lived refresh tokens can get new access tokens
- **TLS Required** - Security relies on HTTPS transport

**Key Principle:**
> "OAuth 2.0 is about authorization, not authentication. It allows a user to grant a third-party application limited access to their resources on another service, without exposing their credentials. The user stays in control of what access they grant and can revoke it at any time."

**Alternative Formulation:**
> "OAuth 2.0 provides a secure way for applications to access user data without ever seeing the user's password. Think of it like giving a valet key to a parking attendant - they can drive your car, but they can't open the trunk or glove compartment."

## 🔍 Core Concepts Deep Dive

### 1. Authentication vs Authorization

**Critical Distinction:**

| Aspect | Authentication | Authorization |
|--------|---------------|---------------|
| **Question** | "Who are you?" | "What can you do?" |
| **Proves** | Identity | Permissions |
| **Example** | Login with username/password | Access to specific resources |
| **OAuth 2.0** | NOT provided by OAuth 2.0 | Core purpose of OAuth 2.0 |

**Important:**
- OAuth 2.0 is an **authorization** framework, NOT authentication
- OpenID Connect (OIDC) adds authentication layer on top of OAuth 2.0
- Many people confuse these - OAuth doesn't verify who you are, it verifies what you can access

```typescript
// OAuth 2.0 tells you:
"This token allows access to: read:emails, write:calendar"

// OAuth 2.0 does NOT tell you:
"This user is john@example.com"

// OpenID Connect (OIDC) adds identity:
"This user is john@example.com AND has these permissions"
```

### 2. Scopes

**Definition:**
Scopes define the specific permissions/access levels that a client is requesting. They limit what the access token can do.

**Use Case:** Web applications with a backend server (confidential clients)

**Implementation Example:**

```typescript
// Step 1: Generate Authorization URL
const authorizationUrl = new URL('https://accounts.google.com/o/oauth2/v2/auth');
authorizationUrl.searchParams.set('client_id', process.env.GOOGLE_CLIENT_ID);
authorizationUrl.searchParams.set('redirect_uri', 'https://yourapp.com/callback');
authorizationUrl.searchParams.set('response_type', 'code');
authorizationUrl.searchParams.set('scope', 'openid email profile');
authorizationUrl.searchParams.set('state', generateRandomState()); // CSRF protection

// Redirect user to: authorizationUrl.toString()

// Step 2: Handle Callback (user returns with code)
app.get('/callback', async (req, res) => {
  const { code, state } = req.query;
  
  // Verify state matches (CSRF protection)
  if (state !== req.session.oauthState) {
    return res.status(400).send('Invalid state');
  }
  
  // Step 3: Exchange code for tokens
  const tokenResponse = await fetch('https://oauth2.googleapis.com/token', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({
      grant_type: 'authorization_code',
      code: code,
      redirect_uri: 'https://yourapp.com/callback',
      client_id: process.env.GOOGLE_CLIENT_ID,
      client_secret: process.env.GOOGLE_CLIENT_SECRET // Server-side only!
    })
  });
  
  const tokens = await tokenResponse.json();
  // {
  //   access_token: "ya29.a0AfH6...",
  //   refresh_token: "1//0g...",
  //   expires_in: 3600,
  //   token_type: "Bearer",
  //   scope: "openid email profile"
  // }
  
  // Step 4: Use access token to get user data
  const userResponse = await fetch('https://www.googleapis.com/oauth2/v2/userinfo', {
    headers: { 'Authorization': `Bearer ${tokens.access_token}` }
  });
  
  const user = await userResponse.json();
  // { id: "123", email: "user@gmail.com", name: "John Doe", picture: "..." }
  
  // Store tokens securely, create session
  req.session.user = user;
  req.session.accessToken = tokens.access_token;
  req.session.refreshToken = tokens.refresh_token;
  
  res.redirect('/dashboard');
});
```

### 2. Authorization Code Flow with PKCE (Public Clients)

**Use Case:** Single Page Applications (SPAs), Mobile Apps, Desktop Apps

**Why PKCE?**
- Public clients cannot securely store `client_secret`
- PKCE (Proof Key for Code Exchange) adds security without secrets
- Prevents authorization code interception attacks

```
┌─────────────────────────────────────────────────────────────┐
│              PKCE FLOW ADDITIONS                             │
│                                                              │
│  Before Authorization:                                       │
│  ┌────────────────────────────────────────────────────┐     │
│  │  1. Generate random code_verifier (43-128 chars)   │     │
│  │     code_verifier = "dBjftJeZ4CVP-mB92K27uhbUJU1p1│     │
│  │                      r_wW1gFWFOEjXk..."            │     │
│  │                                                     │     │
│  │  2. Create code_challenge = SHA256(code_verifier)  │     │
│  │     code_challenge = "E9Melhoa2OwvFrEMTJguCHaoeK1│     │
│  │                       t8URWbuGJSstw-cM"           │     │
│  │                                                     │     │
│  │  3. Send code_challenge in auth request            │     │
│  │                                                     │     │
│  │  4. Send code_verifier when exchanging code        │     │
│  │                                                     │     │
│  │  Server verifies: SHA256(code_verifier) ==         │     │
│  │                   code_challenge                    │     │
│  └────────────────────────────────────────────────────┘     │
│                                                              │
│  Security: Even if code is intercepted, attacker doesn't    │
│  have code_verifier to exchange it for tokens               │
└─────────────────────────────────────────────────────────────┘
```

**Implementation Example (SPA/React):**

```typescript
// Helper functions for PKCE
function generateCodeVerifier(): string {
  const array = new Uint8Array(32);
  crypto.getRandomValues(array);
  return base64UrlEncode(array);
}

async function generateCodeChallenge(verifier: string): Promise<string> {
  const encoder = new TextEncoder();
  const data = encoder.encode(verifier);
  const hash = await crypto.subtle.digest('SHA-256', data);
  return base64UrlEncode(new Uint8Array(hash));
}

function base64UrlEncode(buffer: Uint8Array): string {
  return btoa(String.fromCharCode(...buffer))
    .replace(/\+/g, '-')
    .replace(/\//g, '_')
    .replace(/=+$/, '');
}

// Step 1: Start OAuth flow
async function startOAuthFlow() {
  const codeVerifier = generateCodeVerifier();
  const codeChallenge = await generateCodeChallenge(codeVerifier);
  const state = generateRandomState();
  
  // Store for later verification
  sessionStorage.setItem('code_verifier', codeVerifier);
  sessionStorage.setItem('oauth_state', state);
  
  const authUrl = new URL('https://accounts.google.com/o/oauth2/v2/auth');
  authUrl.searchParams.set('client_id', 'your-client-id');
  authUrl.searchParams.set('redirect_uri', 'https://yourapp.com/callback');
  authUrl.searchParams.set('response_type', 'code');
  authUrl.searchParams.set('scope', 'openid email profile');
  authUrl.searchParams.set('state', state);
  authUrl.searchParams.set('code_challenge', codeChallenge);
  authUrl.searchParams.set('code_challenge_method', 'S256');
  
  window.location.href = authUrl.toString();
}

// Step 2: Handle callback
async function handleCallback() {
  const params = new URLSearchParams(window.location.search);
  const code = params.get('code');
  const state = params.get('state');
  
  // Verify state
  if (state !== sessionStorage.getItem('oauth_state')) {
    throw new Error('Invalid state');
  }
  
  const codeVerifier = sessionStorage.getItem('code_verifier');
  
  // Exchange code for tokens (no client_secret needed!)
  const tokenResponse = await fetch('https://oauth2.googleapis.com/token', {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({
      grant_type: 'authorization_code',
      code: code,
      redirect_uri: 'https://yourapp.com/callback',
      client_id: 'your-client-id',
      code_verifier: codeVerifier // PKCE verification
    })
  });
  
  const tokens = await tokenResponse.json();
  // Store tokens securely (NOT in localStorage for access tokens!)
  return tokens;
}
```

```typescript
class TokenManager {
  private accessToken: string | null = null;
  private refreshToken: string | null = null;
  private expiresAt: number = 0;
  
  async getValidAccessToken(): Promise<string> {
    // Check if token is still valid (with 60s buffer)
    if (this.accessToken && Date.now() < this.expiresAt - 60000) {
      return this.accessToken;
    }
    
    // Refresh the token
    if (this.refreshToken) {
      return this.refresh();
    }
    
    throw new Error('No valid token available. User must re-authenticate.');
  }
  
  private async refresh(): Promise<string> {
    const response = await fetch('https://oauth2.googleapis.com/token', {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({
        grant_type: 'refresh_token',
        refresh_token: this.refreshToken!,
        client_id: process.env.GOOGLE_CLIENT_ID!,
        client_secret: process.env.GOOGLE_CLIENT_SECRET!
      })
    });
    
    if (!response.ok) {
      // Refresh token might be revoked
      throw new Error('Failed to refresh token');
    }
    
    const tokens = await response.json();
    
    this.accessToken = tokens.access_token;
    this.expiresAt = Date.now() + (tokens.expires_in * 1000);
    
    // Some providers rotate refresh tokens
    if (tokens.refresh_token) {
      this.refreshToken = tokens.refresh_token;
    }
    
    return this.accessToken;
  }
}

// Usage with automatic retry
async function makeAuthenticatedRequest(url: string, tokenManager: TokenManager) {
  const token = await tokenManager.getValidAccessToken();
  
  const response = await fetch(url, {
    headers: { 'Authorization': `Bearer ${token}` }
  });
  
  if (response.status === 401) {
    // Token might have been revoked, force refresh
    const newToken = await tokenManager.refresh();
    return fetch(url, {
      headers: { 'Authorization': `Bearer ${newToken}` }
    });
  }
  
  return response;
}
```

## ⚠️ Common Pitfalls

### 1. Storing Tokens Insecurely

**❌ Wrong:**

```typescript
// NEVER store access tokens in localStorage (XSS vulnerable)
localStorage.setItem('access_token', token);

// NEVER store tokens in URL
window.location.href = `/dashboard?token=${accessToken}`;

// NEVER log tokens
console.log('Token:', accessToken);
```

**✅ Correct:**

```typescript
// Server-side: Store in encrypted session
req.session.accessToken = token;

// SPA: Store access token in memory only
let accessToken = null; // In-memory variable

// SPA: Store refresh token in httpOnly cookie
res.cookie('refresh_token', refreshToken, {
  httpOnly: true,    // Not accessible via JavaScript
  secure: true,      // HTTPS only
  sameSite: 'strict' // CSRF protection
});
```

### 2. Not Validating State Parameter

**❌ Wrong:**

```typescript
// Missing state parameter = CSRF vulnerability
const authUrl = `https://auth.example.com/authorize?
  client_id=${clientId}&
  redirect_uri=${redirectUri}&
  response_type=code`;
// No state parameter!

// Not validating state on callback
app.get('/callback', (req, res) => {
  const { code } = req.query;
  // Missing state validation!
  exchangeCodeForTokens(code);
});
```

**✅ Correct:**

```typescript
// Generate and store state
const state = crypto.randomBytes(32).toString('hex');
req.session.oauthState = state;

const authUrl = `https://auth.example.com/authorize?
  client_id=${clientId}&
  redirect_uri=${redirectUri}&
  response_type=code&
  state=${state}`;

// Validate state on callback
app.get('/callback', (req, res) => {
  const { code, state } = req.query;
  
  if (state !== req.session.oauthState) {
    return res.status(400).send('Invalid state - possible CSRF attack');
  }
  
  delete req.session.oauthState; // One-time use
  exchangeCodeForTokens(code);
});
```

### 3. Using Implicit Flow for SPAs

**❌ Wrong:**

```typescript
// Implicit flow exposes token in URL (deprecated!)
const authUrl = `https://auth.example.com/authorize?
  response_type=token&  // ❌ Token in URL fragment
  client_id=${clientId}`;

// Token visible in: https://yourapp.com/callback#access_token=abc123
```

**✅ Correct:**

```typescript
// Use Authorization Code + PKCE for SPAs
const authUrl = `https://auth.example.com/authorize?
  response_type=code&           // ✅ Code, not token
  client_id=${clientId}&
  code_challenge=${codeChallenge}&
  code_challenge_method=S256`;

// Code exchanged securely for tokens
```

### 4. Not Verifying ID Token

**❌ Wrong:**

```typescript
// Just decoding without verification
const decoded = jwt.decode(idToken); // ❌ No signature verification!
const user = decoded;
```

**✅ Correct:**

```typescript
// Verify signature, issuer, audience, and expiration
const decoded = jwt.verify(idToken, publicKey, {
  algorithms: ['RS256'],
  issuer: 'https://accounts.google.com',
  audience: 'your-client-id'
});

// Additional checks
if (decoded.exp < Date.now() / 1000) {
  throw new Error('Token expired');
}

if (decoded.nonce !== expectedNonce) {
  throw new Error('Invalid nonce');
}
```

### 5. Requesting Too Many Scopes

**❌ Wrong:**

```typescript
// Requesting all possible scopes
const scope = 'openid email profile calendar drive gmail contacts photos';
// User sees scary permission screen, abandons flow
```

**✅ Correct:**

```typescript
// Request minimum scopes needed (progressive consent)
// Initial login - just identity
const scope = 'openid email profile';

// Later, when user needs calendar feature
const additionalScope = 'calendar.readonly';
// Request incremental authorization
```

### 6. Exposing Client Secret

**❌ Wrong:**

```typescript
// Client secret in frontend code
const response = await fetch('/api/token', {
  body: JSON.stringify({
    client_secret: 'super-secret-key', // ❌ Exposed in browser!
    code: authCode
  })
});

// Client secret in mobile app
const clientSecret = "hardcoded-secret"; // ❌ Can be extracted!
```

**✅ Correct:**

```typescript
// Client secret only on backend
// Backend endpoint handles token exchange
app.post('/api/auth/callback', async (req, res) => {
  const { code } = req.body;
  
  const tokens = await fetch('https://auth.example.com/token', {
    method: 'POST',
    body: new URLSearchParams({
      code,
      client_secret: process.env.CLIENT_SECRET, // ✅ Server-side only
      // ...
    })
  });
  
  // Return tokens to frontend (without exposing secret)
});

// For public clients (SPA, mobile), use PKCE instead
```

## ✅ Best Practices

### 1. Token Security

✅ **Do:**
- Store access tokens in memory (SPA)
- Store refresh tokens in httpOnly cookies
- Use short-lived access tokens (< 1 hour)
- Encrypt tokens at rest (server-side)
- Rotate refresh tokens on use

❌ **Don't:**
- Store tokens in localStorage
- Store tokens in URL parameters
- Log tokens anywhere
- Use long-lived access tokens
- Share tokens between users

### 2. Authorization Flow

✅ **Do:**
- Always use PKCE for public clients
- Validate state parameter (CSRF protection)
- Use Authorization Code flow (not Implicit)
- Verify redirect_uri strictly
- Use nonce for OpenID Connect

❌ **Don't:**
- Use Implicit flow (deprecated)
- Skip state validation
- Use password grant (deprecated)
- Allow open redirects
- Reuse authorization codes

### 3. Scope Management

✅ **Do:**
- Request minimum required scopes
- Use incremental authorization
- Clearly explain requested permissions
- Respect scope limitations
- Validate scopes on resource server

❌ **Don't:**
- Request all scopes upfront
- Ignore scope parameter
- Use overly broad scopes
- Skip scope validation
- Assume token has all permissions

### 4. Token Validation

✅ **Do:**
- Verify JWT signatures
- Check token expiration
- Validate issuer and audience
- Use secure key storage (JWKS)
- Implement token revocation

❌ **Don't:**
- Just decode without verifying
- Ignore expiration claims
- Accept tokens from any issuer
- Hardcode signing keys
- Skip revocation checks

### 5. Error Handling

✅ **Do:**
- Handle token expiration gracefully
- Implement automatic token refresh
- Provide clear error messages
- Log security events (without tokens)
- Handle revocation scenarios

❌ **Don't:**
- Expose internal errors to users
- Log sensitive token data
- Ignore refresh failures
- Crash on expired tokens
- Skip error logging

## 🏛️ Implementation Examples

### Example 1: Complete Express.js OAuth 2.0 Implementation

```typescript
import express from 'express';
import session from 'express-session';
import crypto from 'crypto';

const app = express();

// Session configuration
app.use(session({
  secret: process.env.SESSION_SECRET!,
  resave: false,
  saveUninitialized: false,
  cookie: { secure: true, httpOnly: true }
}));

// OAuth configuration
const oauth = {
  clientId: process.env.GOOGLE_CLIENT_ID!,
  clientSecret: process.env.GOOGLE_CLIENT_SECRET!,
  authUrl: 'https://accounts.google.com/o/oauth2/v2/auth',
  tokenUrl: 'https://oauth2.googleapis.com/token',
  userInfoUrl: 'https://www.googleapis.com/oauth2/v2/userinfo',
  redirectUri: 'https://yourapp.com/auth/callback',
  scopes: ['openid', 'email', 'profile']
};

// Start OAuth flow
app.get('/auth/login', (req, res) => {
  const state = crypto.randomBytes(32).toString('hex');
  req.session.oauthState = state;
  
  const authUrl = new URL(oauth.authUrl);
  authUrl.searchParams.set('client_id', oauth.clientId);
  authUrl.searchParams.set('redirect_uri', oauth.redirectUri);
  authUrl.searchParams.set('response_type', 'code');
  authUrl.searchParams.set('scope', oauth.scopes.join(' '));
  authUrl.searchParams.set('state', state);
  authUrl.searchParams.set('access_type', 'offline'); // Get refresh token
  authUrl.searchParams.set('prompt', 'consent'); // Force consent for refresh token
  
  res.redirect(authUrl.toString());
});

// Handle OAuth callback
app.get('/auth/callback', async (req, res) => {
  const { code, state, error } = req.query;
  
  // Handle errors
  if (error) {
    return res.redirect(`/login?error=${error}`);
  }
  
  // Validate state (CSRF protection)
  if (state !== req.session.oauthState) {
    return res.status(400).send('Invalid state parameter');
  }
  delete req.session.oauthState;
  
  try {
    // Exchange code for tokens
    const tokenResponse = await fetch(oauth.tokenUrl, {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({
        grant_type: 'authorization_code',
        code: code as string,
        redirect_uri: oauth.redirectUri,
        client_id: oauth.clientId,
        client_secret: oauth.clientSecret
      })
    });
    
    if (!tokenResponse.ok) {
      throw new Error('Token exchange failed');
    }
    
    const tokens = await tokenResponse.json();
    
    // Get user info
    const userResponse = await fetch(oauth.userInfoUrl, {
      headers: { 'Authorization': `Bearer ${tokens.access_token}` }
    });
    
    const user = await userResponse.json();
    
    // Store in session
    req.session.user = user;
    req.session.accessToken = tokens.access_token;
    req.session.refreshToken = tokens.refresh_token;
    req.session.tokenExpiry = Date.now() + (tokens.expires_in * 1000);
    
    res.redirect('/dashboard');
  } catch (error) {
    console.error('OAuth error:', error);
    res.redirect('/login?error=auth_failed');
  }
});

// Middleware to check authentication
const requireAuth = async (req, res, next) => {
  if (!req.session.user) {
    return res.redirect('/auth/login');
  }
  
  // Check if token needs refresh
  if (Date.now() >= req.session.tokenExpiry - 60000) {
    try {
      await refreshAccessToken(req);
    } catch (error) {
      return res.redirect('/auth/login');
    }
  }
  
  next();
};

// Refresh access token
async function refreshAccessToken(req) {
  const response = await fetch(oauth.tokenUrl, {
    method: 'POST',
    headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
    body: new URLSearchParams({
      grant_type: 'refresh_token',
      refresh_token: req.session.refreshToken,
      client_id: oauth.clientId,
      client_secret: oauth.clientSecret
    })
  });
  
  if (!response.ok) {
    throw new Error('Token refresh failed');
  }
  
  const tokens = await response.json();
  
  req.session.accessToken = tokens.access_token;
  req.session.tokenExpiry = Date.now() + (tokens.expires_in * 1000);
  
  if (tokens.refresh_token) {
    req.session.refreshToken = tokens.refresh_token;
  }
}

// Protected route
app.get('/dashboard', requireAuth, (req, res) => {
  res.json({ user: req.session.user });
});
```

### Example 2: React SPA with PKCE

```typescript
// auth.ts - OAuth utilities for SPA
export class OAuthClient {
  private config: OAuthConfig;
  private accessToken: string | null = null;
  private tokenExpiry: number = 0;
  
  constructor(config: OAuthConfig) {
    this.config = config;
  }
  
  // Generate PKCE challenge
  private async generatePKCE() {
    const array = new Uint8Array(32);
    crypto.getRandomValues(array);
    const verifier = this.base64UrlEncode(array);
    
    const encoder = new TextEncoder();
    const data = encoder.encode(verifier);
    const hash = await crypto.subtle.digest('SHA-256', data);
    const challenge = this.base64UrlEncode(new Uint8Array(hash));
    
    return { verifier, challenge };
  }
  
  private base64UrlEncode(buffer: Uint8Array): string {
    return btoa(String.fromCharCode(...buffer))
      .replace(/\+/g, '-')
      .replace(/\//g, '_')
      .replace(/=+$/, '');
  }
  
  // Start login flow
  async login() {
    const { verifier, challenge } = await this.generatePKCE();
    const state = crypto.randomUUID();
    
    // Store for callback
    sessionStorage.setItem('pkce_verifier', verifier);
    sessionStorage.setItem('oauth_state', state);
    
    const authUrl = new URL(this.config.authUrl);
    authUrl.searchParams.set('client_id', this.config.clientId);
    authUrl.searchParams.set('redirect_uri', this.config.redirectUri);
    authUrl.searchParams.set('response_type', 'code');
    authUrl.searchParams.set('scope', this.config.scopes.join(' '));
    authUrl.searchParams.set('state', state);
    authUrl.searchParams.set('code_challenge', challenge);
    authUrl.searchParams.set('code_challenge_method', 'S256');
    
    window.location.href = authUrl.toString();
  }
  
  // Handle callback
  async handleCallback(): Promise<User> {
    const params = new URLSearchParams(window.location.search);
    const code = params.get('code');
    const state = params.get('state');
    const error = params.get('error');
    
    if (error) {
      throw new Error(`OAuth error: ${error}`);
    }
    
    // Validate state
    const savedState = sessionStorage.getItem('oauth_state');
    if (state !== savedState) {
      throw new Error('Invalid state - possible CSRF attack');
    }
    
    const verifier = sessionStorage.getItem('pkce_verifier');
    
    // Clean up
    sessionStorage.removeItem('oauth_state');
    sessionStorage.removeItem('pkce_verifier');
    
    // Exchange code for tokens
    const response = await fetch(this.config.tokenUrl, {
      method: 'POST',
      headers: { 'Content-Type': 'application/x-www-form-urlencoded' },
      body: new URLSearchParams({
        grant_type: 'authorization_code',
        code: code!,
        redirect_uri: this.config.redirectUri,
        client_id: this.config.clientId,
        code_verifier: verifier!
      })
    });
    
    if (!response.ok) {
      throw new Error('Token exchange failed');
    }
    
    const tokens = await response.json();
    
    // Store access token in memory
    this.accessToken = tokens.access_token;
    this.tokenExpiry = Date.now() + (tokens.expires_in * 1000);
    
    // Store refresh token in httpOnly cookie via backend
    if (tokens.refresh_token) {
      await this.storeRefreshToken(tokens.refresh_token);
    }
    
    // Get user info
    return this.getUserInfo();
  }
  
  // Store refresh token securely via backend
  private async storeRefreshToken(refreshToken: string) {
    await fetch('/api/auth/store-refresh-token', {
      method: 'POST',
      credentials: 'include',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ refreshToken })
    });
  }
  
  // Get valid access token (refresh if needed)
  async getAccessToken(): Promise<string> {
    if (this.accessToken && Date.now() < this.tokenExpiry - 60000) {
      return this.accessToken;
    }
    
    // Refresh via backend (which has httpOnly cookie)
    const response = await fetch('/api/auth/refresh', {
      method: 'POST',
      credentials: 'include'
    });
    
    if (!response.ok) {
      throw new Error('Token refresh failed');
    }
    
    const { access_token, expires_in } = await response.json();
    this.accessToken = access_token;
    this.tokenExpiry = Date.now() + (expires_in * 1000);
    
    return this.accessToken;
  }
  
  // Fetch with authentication
  async fetch(url: string, options: RequestInit = {}): Promise<Response> {
    const token = await this.getAccessToken();
    
    return fetch(url, {
      ...options,
      headers: {
        ...options.headers,
        'Authorization': `Bearer ${token}`
      }
    });
  }
  
  // Get user info
  async getUserInfo(): Promise<User> {
    const response = await this.fetch(this.config.userInfoUrl);
    return response.json();
  }
  
  // Logout
  async logout() {
    this.accessToken = null;
    this.tokenExpiry = 0;
    
    // Clear refresh token cookie via backend
    await fetch('/api/auth/logout', {
      method: 'POST',
      credentials: 'include'
    });
    
    window.location.href = '/';
  }
}

// React hook
export function useAuth() {
  const [user, setUser] = useState<User | null>(null);
  const [loading, setLoading] = useState(true);
  const client = useMemo(() => new OAuthClient(config), []);
  
  useEffect(() => {
    // Check for callback
    if (window.location.search.includes('code=')) {
      client.handleCallback()
        .then(setUser)
        .catch(console.error)
        .finally(() => {
          window.history.replaceState({}, '', window.location.pathname);
          setLoading(false);
        });
    } else {
      // Check existing session
      client.getUserInfo()
        .then(setUser)
        .catch(() => setUser(null))
        .finally(() => setLoading(false));
    }
  }, []);
  
  return {
    user,
    loading,
    login: () => client.login(),
    logout: () => client.logout(),
    fetch: (url: string, options?: RequestInit) => client.fetch(url, options)
  };
}
```

```typescript
// Service-to-service authentication using Client Credentials
class ServiceClient {
  private token: string | null = null;
  private tokenExpiry: number = 0;
  
  async call(service: string, endpoint: string) {
    if (!this.token || Date.now() >= this.tokenExpiry) {
      await this.authenticate();
    }
    
    return fetch(`https://${service}.internal/${endpoint}`, {
      headers: { 'Authorization': `Bearer ${this.token}` }
    });
  }
  
  private async authenticate() {
    const response = await fetch('https://auth.internal/oauth/token', {
      method: 'POST',
      body: new URLSearchParams({
        grant_type: 'client_credentials',
        client_id: process.env.SERVICE_CLIENT_ID!,
        client_secret: process.env.SERVICE_CLIENT_SECRET!,
        scope: 'service:read service:write'
      })
    });
    
    const { access_token, expires_in } = await response.json();
    this.token = access_token;
    this.tokenExpiry = Date.now() + (expires_in * 1000);
  }
}
```

## 🎓 Summary

### Key Takeaways

1. **OAuth 2.0** is for **authorization**, not authentication (use OIDC for identity)
2. **Authorization Code + PKCE** is the recommended flow for all clients
3. **Access tokens** are short-lived; **refresh tokens** are long-lived
4. **Scopes** define what permissions a token has
5. **State parameter** prevents CSRF attacks
6. **Never** store tokens in localStorage or expose client secrets
7. **Always** validate tokens properly (signature, expiration, audience)

### Flow Selection

| Client Type | Recommended Flow |
|------------|------------------|
| Web App (server) | Authorization Code |
| SPA (React, Vue) | Authorization Code + PKCE |
| Mobile App | Authorization Code + PKCE |
| CLI Tool | Device Authorization |
| Microservice | Client Credentials |

### Security Checklist

- [ ] Using Authorization Code (not Implicit)
- [ ] PKCE for public clients
- [ ] State parameter for CSRF protection
- [ ] Tokens stored securely (not localStorage)
- [ ] Client secret only on server
- [ ] JWT signatures verified
- [ ] Token expiration checked
- [ ] Minimum scopes requested
- [ ] HTTPS everywhere
- [ ] Refresh token rotation
